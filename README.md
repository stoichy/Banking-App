Banking application written in Java that offers several functionalities such as:

-Three different types of accounts: business, savings or classic.Each account can have multiple cards, one of two types, a classic one or a one time usage one.

-Access to several kinds of financial reports that show a history of payments.

-Different types of cashback for payment to specific commerciants.

-Ability to use different service plans, each one bringing specific
benefits, such as descreased interests or increased cashback.

-Group payments: custom payments between several users.

Several POO design patterns were used in the implementation, such as:
Builder, Singleton, Factory and Visitor.
